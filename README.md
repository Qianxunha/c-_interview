1. c++中构造函数与析构函数 能否抛出异常
   答：c++中构造函数可以抛出异常，析构函数不能抛出异常。
       构造函数在初始化过程中，如果申请文件资源，内存资源失败，构造函数没有返回值。可以通过抛出异常捕获；检测出类对象是否申请成功。如果
       抛出异常，c++自动析构销毁，不会造成内存泄漏。

       析构函数如果抛出异常的话，会导致程序崩溃，引发一些未定义行为。（c++编译器禁止抛出异常）

2. c++三大特性
   封装：将数据和方法封装成一个函数
   继承：子类继承父类
   多态：允许有统一的函数接口操作不同的类型参数对象。

   2.1多态类型： 静态多态：在程序编译时通过函数重载和模版实现
                动态多态：在程序运行时动态绑定，通过虚函数实现
   
   2.2动态多态实现条件： 1）发生继承，子类继承父类
                       2）在基类中定义虚函数 virtual function() 派生类重写虚函数
                       3）派生类的对象引用或者指针发生函数重载
   2.3动态多态实现原理： 在类中有虚函数，在编译阶段会生成一张虚函数表vtable;
                       对象中包含虚指针vptr 指向虚函数表
                       基类指针指向子类对象时，通过vptr 找到对应子类的虚表
                       从虚表中调用对应重写函数，实现运行时多态。
